## 中

- [x] **Windowsで読めないフォルダーの扱いをCIで確認する**（2026-10-12 完了）
  - 読めないフォルダーがあっても検査を続けて `partial` を返すテストは、`chmod` で読み取りを禁止する方式です。
    Windows では `chmod` で読み取りを禁止できないため、Windows のCIではスキップされています（2026-10-12 の初回CIで確認）。
  - Windows 向けに、ACL（`icacls` の deny 指定）で読み取りを拒否するテストを追加する。
    後片付けで拒否設定を外し、一時フォルダーを削除できるようにする。
  - 同じ方法で一覧取得を拒否したジャンクションを作れば、旧ジャンクション（`My Music` 等）に相当するケースも確認できる。
  - 完了条件: Windows のCIジョブで、該当テストがスキップされずに成功する。
  - 結果: ACL の deny を付けても、GitHub の Windows ランナーでは `SeBackupPrivilege` と `SeRestorePrivilege` が有効なため、
    拒否が素通りされてスキップになった（一時ブランチでの診断で確認）。
    特権をすべて外し、Administrators を deny-only にした制限トークンでテストを実行するよう変更し、
    Windows（Python 3.11 / 3.14）で「読めないフォルダーでも `partial` で続行」と「旧ジャンクションで検査が止まらない」の
    両テストが実行・成功した。

- [ ] **MCPのキャンセル時に実行中のエンジンを止める**
  - 現在は順番待ちの検査ならキャンセルで中止されますが、実行中のエンジンはタイムアウトまで動き続けます。
  - キャンセルを `run_bounded` に伝えてプロセスを kill する仕組みが必要です。

- [ ] **子プロセスをまとめて停止できるようにする**
  - タイムアウトや出力超過のときに kill されるのは、直接起動したエンジンだけです。
  - POSIX はプロセスグループ（`start_new_session` と `killpg`）、Windows は Job Object で、子孫プロセスまで止める。

- [ ] **ClamAVの定義ファイルの鮮度を確認する**
  - 現在は「定義の鮮度は未検証」という警告のみです。
  - `clamscan --version` の定義日付などを読み、古い場合は警告または `partial` にする。

- [ ] **Wazuhの端末同一性と鮮度を確認する**
  - 現在の `freshness` は常に `unverified` です。
  - エージェント名・最終接続時刻・インベントリの収集時刻を取得して結果に含める。
  - 他のインデックスへの読み取り権限が必要になるため、最小権限の方針とあわせて検討する。

- [ ] **Wazuhで10000件を超える結果を取得できるようにする**
  - 現在の `offset` は `from`/`size` 方式のため、上限は9500です。
  - `search_after` と Point in Time を使えば上限なく取得できますが、AI に続きの位置を渡す形式を設計し直す必要があります。

- [ ] **実際のMCPクライアントで長時間の検査を試す**
  - Claude Desktop・Claude Code などで、10分程度の検査中に切断されないか、進捗通知でタイムアウトが延長されるかを確認する。

- [ ] **macOS以外のロックファイルとSBOMを用意する**
  - `requirements-agent.lock` と SBOM は macOS x86_64 / CPython 3.14.7 専用です。Windows では pywin32 などの依存が増えます。
  - Windows・Linux・macOS arm64 向けのプロファイルを生成する。

## 要判断

- [ ] **clamdscan（常駐デーモン経由の検査）に対応するか**
  - 利点: 定義ファイルを毎回読み込まないため速く、メモリ使用も1プロセス分で済みます。
  - 欠点: ファイルサイズ上限やシンボリックリンクの扱いが `clamd.conf` 側の設定になり、この基盤では強制できません。また clamd は別ユーザーで動くことが多く、`--fdpass` などの権限設計が必要です。

- [ ] **独自コードのライセンスを正式に適用する**
  - MIT を提案済みですが、まだ適用していません（[license-recommendation.md](license-recommendation.md)）。

- [ ] **読み取り専用の注釈（`readOnlyHint`）を残すか**
  - クライアントによっては、この注釈を理由に承認なしでツールを実行します。
  - 所有者の同意を毎回求めたい場合は、注釈を外すかクライアント側で承認必須に設定する。
